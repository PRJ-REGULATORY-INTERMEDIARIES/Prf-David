# CLAUDE Track B - O6 Part-whole analysis

Purpose: state the bearer (actor / relation / position / configuration / law / regime) and the boundary of every property claimed anywhere in this track, and list property claims that were refused a higher bearer. "Statement" is used as the bearer type for properties that belong to a single institutional statement (a normative assignment) and that are not lifted to an actor or relation; V8 keeps the statement as the unit of coding, distinct from the unit of analysis (relationship).

Bearer types used: STATEMENT (assignment inside one statement), RELATION (typed actor-to-actor link), POSITION (place of a relation or step inside a configuration, derived from stated order or option), CONFIGURATION (a grouped set, C-IDs), LAW (an instrument as a whole), REGIME. No property is assigned to LAW or REGIME in this track.

## 3. Result of O6

All 46 claims have a bearer at or below the CONFIGURATION level except PW-45, which asserts the absence of any LAW or REGIME claim. Fourteen lifts were refused. The most consequential refusals concern frequency or connectivity (RL-02), a word in the text that sounds like a structural property (RL-03), and a precondition on one agreement (RL-04). The operation largely restates V8's cross-level error list applied to this dataset; the added element is the explicit bearer column for each claim.
