# Protocolo de adjudicação humana

## Gatilhos mandatórios

Criar item de revisão humana para toda diferença que envolva:

| Código | Gatilho |
|---|---|
| H1 | existência/não existência de relação material |
| H2 | identidade de ator/contraparte |
| H3 | direção ou modalidade com efeito na interpretação de governança |
| H4 | pertencimento ou fronteira de configuração |
| H5 | existência, número ou fronteira de arquitetura |
| H6 | classificação de integração, diferenciação ou sobreposição |
| H7 | alegação dependente de ausência |
| H8 | dependência jurídica externa |
| H9 | possível sobre-inferência |
| H10 | proposição material apenas V8 ou apenas RGAM |
| H11 | níveis de parada distintos com consequência substantiva |

## Forma cega quanto ao mérito metodológico

Cada item contém: identificador; caso; níveis C aplicáveis; evidência jurídica comum e âncoras; Proposição A; Proposição B; descrição precisa da divergência; gatilhos; pergunta humana exata; referências nativas de cada braço. Não usar linguagem persuasiva ou conclusiva como “RGAM melhorou”, “V8 deixou de captar”, “superior” ou “mais sofisticado”.

O adjudicador (Igor) decide a leitura apoiada, leitura concorrente ou incerteza não resolvida, com fundamentação e limites. A pergunta incide sobre proposição/evidência, nunca sobre qual método deveria vencer. O executor não preenche a decisão humana e não simula adjudicação.

Depois da adjudicação, o sintetizador registra o efeito metodológico somente se ele decorrer da decisão e das regras congeladas. Itens ainda abertos impedem síntese final para a questão/caso afetado; se materialmente impeditivos, o resultado é `COMPARISON_INDETERMINATE`.
