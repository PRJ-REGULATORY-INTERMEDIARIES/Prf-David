# Dimensões D1–D8

Cada proposição material pareada ou não pareada recebe D1–D8 aplicáveis. Não há soma, pesos ou escore composto.

| Código | Dimensão e pergunta | Status permitido |
|---|---|---|
| D1 | **Suporte jurídico-evidencial:** a proposição é sustentada pelo corpus congelado no nível afirmado? | `SUPPORTED`; `PARTIALLY_SUPPORTED`; `UNSUPPORTED`; `EXTERNAL_DEPENDENCY`; `INDETERMINATE` |
| D2 | **Contribuição informacional substantiva:** algum método recupera informação defensável ausente do outro? | `NONE`; `MINOR`; `MATERIAL` |
| D3 | **Rastreabilidade vertical:** proposição superior pode ser reconstruída até evidência e inferência intermediária? | `EQUIVALENT`; `V8_CLEARER`; `RGAM_CLEARER`; `BOTH_INSUFFICIENT`; `NOT_APPLICABLE` |
| D4 | **Explicitação inferencial:** o método expõe a passagem de evidência inferior a alegação superior? | `EQUIVALENT`; `V8_CLEARER`; `RGAM_CLEARER`; `BOTH_INSUFFICIENT`; `NOT_APPLICABLE` |
| D5 | **Controle de fronteira/sensibilidade:** identifica pressuposto, agrupamento rival, dependência de corpus ou limite relevante? | `EQUIVALENT`; `V8_GAIN`; `RGAM_GAIN`; `DIFFERENT_NONORDERABLE`; `NOT_APPLICABLE` |
| D6 | **Calibração de incerteza:** a assertividade excede a evidência? | `WELL_CALIBRATED_BOTH`; `V8_BETTER_CALIBRATED`; `RGAM_BETTER_CALIBRATED`; `OVERASSERTION_BOTH`; `INDETERMINATE` |
| D7 | **Risco de sobre-inferência:** classificar cada método independentemente. | `NO_EVIDENCE_OF_OVERINFERENCE`; `POSSIBLE_OVERINFERENCE`; `MATERIAL_OVERINFERENCE`; `INDETERMINATE` |
| D8 | **Risco de omissão:** classificar cada método independentemente. | `NO_MATERIAL_OMISSION`; `POSSIBLE_MATERIAL_OMISSION`; `MATERIAL_OMISSION`; `INDETERMINATE` |

D1 avalia a proposição, não a preferência do autor. D7 e D8 requerem colunas separadas para V8 e RGAM. `EXTERNAL_DEPENDENCY`, ausência alegada, conflito ou insuficiência que possa mudar conclusão material exigem aplicação dos gatilhos humanos pertinentes.
