## Applied method

The analysis codes only formal legal design. Level I records evidenced objects, actors, functions, mechanisms, instruments, and typed relations. Level II records authority, discretion, and accountability only when tied to an identified relationship or normative assignment. Level III is reached only through an explicit configuration and a traceable, architecturally significant inference. A statutory assignment without a legally supported counterpart remains an assignment, not an invented actor-to-actor edge. “Telecommunications administrations” is treated as a defined legal category that may include recognized private operating agencies; no particular operator or laboratory is invented.

The inference sequence is legal provision → institutional statement → typed relationship/attribute → configuration → highest warranted higher-order conclusion. The analysis distinguishes the Directive's own formal architecture from implementation, actual operation, effectiveness, and broader regulatory regimes. Frequency is not used as a proxy for significance. The separate eight-operation protocol was not used.
