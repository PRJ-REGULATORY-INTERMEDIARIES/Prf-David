# SYNTHETIC — NOT RESEARCH DATA

`minimal.json` contains entirely invented test identities, an episode, contextual R/I/T roles, a relation, instrument, source, evidence and coding decision. Dates concern the technical fixture, not real-world regulatory events. All records carry is_synthetic=1 and remain candidate. This fixture must never be treated as empirical data or moved to data/public.

The release-success test temporarily simulates non-synthetic metadata inside pytest's temporary directory, while retaining synthetic labels, solely to exercise authorization logic. No resulting file is written to this repository's public data directory.
