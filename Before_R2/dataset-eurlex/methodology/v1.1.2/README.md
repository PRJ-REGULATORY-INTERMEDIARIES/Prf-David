# Experimental protocol correction — v1.1.2

This is a prospective, experimental-only correction to the historical `methodology/v1.1.1` interface. The locked reference methodology at `methodology/v1.1.0/` is unchanged.

In the common experimental output schema, `R`, `I`, and `T` are arrays of actor-label strings. Each array may be empty (`[]`), contain one actor, or contain multiple actors. Actor ordering is not substantive and is normalized independently of list order for later comparison. No reference actor subroles are introduced.

The v1.1.1 correction remains preserved as a historical pre-experiment artifact. This v1.1.2 correction uses no empirical results, does not change the reference schema or benchmark construction, and does not define or execute G0, G1, or G2.

No reference candidate list, candidate IDs, candidate origins, or preselected benchmark locations are experimental inputs. Each condition receives the same complete frozen corpus and independently identifies and codes supported relationships.
