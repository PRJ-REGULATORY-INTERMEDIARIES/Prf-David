# methodology

## Versões bloqueadas

A versão `1.0.0` permanece preservada para auditoria, com seus artefatos e hashes originais na raiz deste diretório:

- `codebook.md`
- `strings.yaml`
- `coding_schema.json`
- `methodology_manifest.yaml`

A versão corrente da metodologia é `v1.1.0`, em [`v1.1.0/`](v1.1.0/). Ela supersede a `1.0.0` após revisão metodológica externa e é a versão destinada à preparação da Etapa 4. A revisão não acessou resultados empíricos nem conteúdo do ato para ajuste de categorias.

O protocolo é source-bounded: strings fazem apenas screening de saliência; decisões substantivas exigem evidência jurídica localizada. O schema de referência é separado do schema experimental mínimo comum a G0/G1/G2.
