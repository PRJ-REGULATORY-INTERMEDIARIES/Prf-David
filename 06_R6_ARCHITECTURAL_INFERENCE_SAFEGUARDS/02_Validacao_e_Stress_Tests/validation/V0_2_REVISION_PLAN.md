5. Write a small decision table for composite norms, n-ary relations, permission/duty/prohibition, missing links, amendment/expiry, and intermediary status.
6. Run a bounded real-law demonstration from primary legal text. Report what is directly coded, what is derived, and where the stopping rule stops inference.
7. Rework claims about novelty, centrality, implementation, and outcomes. Keep network outputs as analytical representations, never legal evidence.
8. Re-run the repository validator after the missing script or correct repository topology is restored.
