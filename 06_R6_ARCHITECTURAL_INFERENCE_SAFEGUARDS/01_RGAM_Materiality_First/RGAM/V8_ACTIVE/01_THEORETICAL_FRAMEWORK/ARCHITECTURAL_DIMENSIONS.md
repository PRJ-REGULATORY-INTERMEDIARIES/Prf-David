# V8 architectural dimensions and significance

The project retains a profile, not a composite score. Each value must state its scale, evidence, inference rule and uncertainty.

| Dimension | Question |
|---|---|
| Centralization | Where is legally consequential decision capacity concentrated? |
| Directness/intermediation | Is governance routed directly or through consequential third parties? |
| Public–private allocation | Which actor families perform which functions? |
| Self-regulatory autonomy | What meaningful governance capacity is retained by regulated actors? |
| Vertical distribution | How is authority allocated across jurisdictional levels? |
| Decision-centre plurality | Are there multiple, partly autonomous centres with meaningful capacity? |
| Relational depth | How many legally consequential stages organize the relevant process? |
| Functional allocation | Where are rule-making, implementation, monitoring, verification and enforcement located? |
| Discretion distribution | Who has which legally structured choices, by function and relation? |
| Accountability structure | Who answers to whom, by what process, assessment and possible consequence? |

## Significance rather than prevalence

Architectural significance may depend on frequency, authority, centrality, exclusivity, sequence, consequence and substitutability. Intermediation centrality additionally profiles prevalence, functional breadth, authority, dependency/indispensability, structural position and regulatory embeddedness. These dimensions remain separate; a frequent intermediary can be peripheral, while a rare mandatory certifier can be consequential.
