# Conceptual presentation

## Argument

V8 frames governance architecture as a legally constituted, relational and multidimensional configuration. The project proposes a methodological layer that makes the transition from legal evidence to architectural claim auditable.

```text
legal text → institutional statements → elements and qualified relationships
          → configurations → warranted architectural profile → possible regime implications
```

The added question is whether different legally qualified arrangements of comparable elements produce different positional or whole-level properties. The proposal remains useful only if that question improves reconstruction beyond counts.

## Consultation focus

- Does the property-bearer distinction clarify V8 or overcomplicate it?
- What minimum boundary rule should support multi-instrument architecture claims?
- How should architectures within regimes and among regimes be operationalized without equating a regime with a statute?
