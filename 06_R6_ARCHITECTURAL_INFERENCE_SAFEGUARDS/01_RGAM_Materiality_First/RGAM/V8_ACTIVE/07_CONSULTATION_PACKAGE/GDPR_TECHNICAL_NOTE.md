# GDPR technical note

The fresh V8 pilot uses a verified historical source and screens 99 articles, 389 paragraph units and 382 point units. The cross-border trace follows Articles 56, 60, 63 and 65, with Articles 64 and 66 as qualifications. It distinguishes the Board's binding dispute-stage decision from the lead authority's final decision.

The defensible preliminary result is a source-linked configuration of conditional escalation and staged authority distribution. It is not a characterization of the whole GDPR, an implementation finding, or independently validated research.
