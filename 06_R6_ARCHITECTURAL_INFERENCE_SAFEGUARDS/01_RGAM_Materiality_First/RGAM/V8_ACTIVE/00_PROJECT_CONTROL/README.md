# V8 active scientific workspace

This workspace reconstructs regulatory governance analysis directly from David Levi-Faur's V8 manuscript. It separates: (1) V8 propositions, (2) operational specifications introduced here, (3) architectural-method hypotheses, and (4) provisional empirical observations.

Its collaboration priorities are: **coordination**—an interoperable, provenance-preserving framework that can be discussed alongside Rotem's coding work and the broader relational-leximetrics dataset without modifying either; **theoretical innovation**—a testable architectural-method contribution rather than a relabelling of V8; and **practical progress**—a bounded, fresh GDPR application that demonstrates the complete evidentiary path to a candidate reconstruction.

The workflow is: documentary source → legal unit → institutional statement → observable governance elements and relational attributes → configuration → explicitly warranted architectural inference → possible regime implications. No architectural label is a primary code.

The GDPR pilot is a fresh, machine-assisted exploratory reconstruction of a fixed historical legal-text baseline. It is not a claim about the current consolidated GDPR, implementation, operation, effectiveness, or the complete European data-protection regime.
