# Communication attachment policy

No duplicate attachment copies were created. Existing deliverables are mapped by path and hash in `index/COMMUNICATION_DELIVERABLE_REGISTER.csv` and `index/COMMUNICATION_ATTACHMENT_REGISTER.csv`.

The presence of a file in a folder named `Enviados` or in a final package is not treated alone as proof that it was transmitted. Where the original email is unavailable, the archival status is `SOURCE_REFERENCE_ONLY` or `TRANSMISSION_NOT_PROVEN`.
