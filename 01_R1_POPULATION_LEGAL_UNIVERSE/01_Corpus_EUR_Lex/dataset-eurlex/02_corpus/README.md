# 02_corpus

Contém a versão textual normalizada e bloqueada do único ato utilizado no exercício.

- `act.md` é a versão canônica autorizada para G0, G1 e G2.
- `act_numbered.md` é uma cópia de auditoria com numeração de linhas.
- `corpus_manifest.yaml` registra proveniência, transformações, contagens e hashes.

A normalização foi estrutural, não analítica: título, preâmbulo, considerandos/recitals, articulado, parágrafos, alíneas e ordem da fonte foram preservados. O ato não contém anexos próprios. Não foram adicionadas classificações, categorias, strings ou marcações substantivas.

O corpus está bloqueado (`locked: true`). Alterações futuras exigem instrução explícita e registro de integridade.
